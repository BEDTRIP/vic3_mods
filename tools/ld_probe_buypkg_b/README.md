# LD Probe BuyPkg B — только первый ключ (исходное E&F)

Проба R0.6 (7.10): в `00_ef_buy_packages.txt` форка ключ `popneed_currency` стоит в каждой `wealth_N` дважды. Три
варианта (A — как есть, B — только первый, C — только второй) подключаются к плейсету «Ledgerdemain» последним модом;
через неделю игры консольное `event zz_probe_bp.1` пишет в `debug.log` строку `BPK|дата|страна|liq …|loc …` — заявки
рынка страны на `liquidity_currency` и `local_currency`. Совпадение A с B — берётся первое значение, с C — последнее,
A = B + C — сумма. Не для игры.
