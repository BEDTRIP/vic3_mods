# LD Probe Rebuild — проба: что теряется при смене владельца здания пересозданием

Мод только для пробы (7.10, схема мода, «передача зданий»). В движке 1.13 нет эффекта смены владельца у стоящего
здания; путь — `remove_building` + `create_building` с новым `add_ownership`. Проба: Британия, Ланкашир, ткацкие
фабрики (13 уровней: финцентр Ланкашира 2, финцентр Хоум-Каунтис 8, сама фабрика 3). Первый месячный пульс Британии
с 1 марта 1836 — строка `EFP|…|before`, пересоздание с владением государства 13 уровней, строка `after`; затем
4 месяца — строки `m1..m4`. Поля: заполненность, касса (доступно / доля), прибыль недели, доли владения (страна /
частные / само здание), уровни у страны, активные методы, идёт ли стройка.
