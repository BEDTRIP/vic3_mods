- **Получен:** 16.10.2026, сборка `ComPatch Morgenroete + Victorian Century` (`_vc/morg+vc done`), мастерская.
- **Статус:** не разобран → задача **VC.13** (П0). Проверено по файлам 16.10: дневник VC
  `restore_cologne_cathedral` (`prussia_kingdom.txt`:1033) и требование пиетизма (:878) есть; собор Morgenröte —
  `building_gaudi_dom`, событие `gaudi.108`. Ответить игроку после правки.

> Patch seems to be working well, but I noticed playing Prussia both Morgenrote and VC have mechanics for Cologne
> Cathedral, so you can build it twice! VC has a barebones "Restore Cologne Cathedral" journal entry where you just
> click one button and wait, then it completes that journal entry and counts toward a requirement for the Conservative
> Order: Pietism entry. Morgenrote has a decision to complete the cathedral and has a bunch of cool events and multiple
> construction phases to it, so if you can I'd really suggest making finishing that count for the Pietism requirement
> and scrapping VC's Cologne Cathedral journal entry.
