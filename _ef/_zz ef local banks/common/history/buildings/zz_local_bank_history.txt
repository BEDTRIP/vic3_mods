### По одному местному банку в столицу каждой страны.
###
### Раньше раздавали в каждый штат — вышло слишком щедро: местная валюта
### появлялась там, где её никто не заказывал, и ИИ не имел повода строить.
### Теперь стартовый банк только в столице, остальное — дело ИИ и игрока
### (см. ai_value у building_local_bank).
###
### Уровень 3, а не 1. Раньше страна без денежной системы получала от E&F
### 2500 local_currency на КАЖДЫЙ штат; теперь весь выпуск идёт из одного
### здания, и уровень 1 (200 единиц при полной занятости) оставил бы весь
### мир в глухом дефиците валюты. Три уровня — это 600 единиц на 3 золота,
### примерно столько и потребляет небольшая страна. Это главный балансный
### рычаг: если валюты в мире мало или много, крутить надо здесь.
###
### Занятость масштабирует выпуск сама: в крошечной стране 3000 рабочих мест
### не заполнятся, и банк выдаст меньше. Это ровно то поведение, которого мы
### добивались формулой по населению — только без формулы.
###
### Файл аддитивный: блоки BUILDINGS складываются.

BUILDINGS = {
	every_country = {
		capital = {
			create_building = {
				building = "building_local_bank"
				level = 3
				reserves = 1
			}
		}
	}
}
