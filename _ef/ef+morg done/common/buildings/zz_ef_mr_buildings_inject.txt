### E&F + Morgenroete ComPatch (Vic3 1.13)
### Add E&F financial PM groups to Morgenroete custom buildings.
###
### Checked against Morgenroete 2.8.3e (62 custom buildings) and E&F 4.07.2026.
### TRY_INJECT is used so that a building removed in a future Morgenroete
### version does not spam the error log.
###
### Stock PM groups are only added to buildings that can actually be privately
### owned. All Andersson / Curie / Lepsius monument+technology buildings are
### government-only (can_build_private = { always = no }), so they get
### pmg_market_liquidity only.
