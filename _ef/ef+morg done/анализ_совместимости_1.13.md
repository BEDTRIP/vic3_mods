## 1. Что делал старый компач

1. **INJECT** `pmg_market_liquidity` (+ stock PMG где нужно) в **57** кастомных зданий Morgenrote.
2. **Расширение** E&F `private_ownership_production_stocks` на 6 MR-зданий + override yearly pulse.
3. **Override** `inflation_on_consumer_goods` и `inflation_on_raw_material` — добавление 5 MR-goods.
4. **Agassiz:** отдельный JE `je_agassiz_find_silver_project`, триггеры, GUI для silver mine E&F.
5. **Tesla:** разрешить `building_ef_private_construction` для construction project; исключить E&F financial building groups из mechanical improvement.

### 2.4 Agassiz-блок — **критическое изменение MR 2.8**

Затронутые файлы старого компача:
- `zz_ef_mr_agassiz_triggers_patch.txt`
- `zz_ef_mr_agassiz_silver_journal_entry.txt`
- `zz_ef_mr_agassiz_sgui_patch.txt`
- `localization/*/zz_ef_mr_agassiz_l_*.yml`

**Статус:** ❌ **не совместимы** с MR 2.8.3.

#### Что изменилось в Morgenrote

| Было (2.6.x + старый компач) | Стало (2.8.x) |
|---|---|
| Отдельные JE: `je_agassiz_find_coal/iron/.../silver_project` | Единый **`je_agassiz_improve_mines_project`** |
| `agassiz_can_find_new_vein_trigger` = OR по типам шахт | `any_scope_building { is_building_group = bg_mining }` |
| GUI с per-ore ветвлением | `mr_geologist_improve_mines_button_effect` + sorter window |
| `agassiz_mine_valid_for_improvement_trigger` | только `bg_mining` |

#### Проблема с E&F silver mine

```text
building_silver_mine → building_group = bg_silver_mining   (E&F)
MR agassiz triggers   → is_building_group = bg_mining      (Morgenrote)
```

Silver mine **не участвует** в «Improve Mining» без компача.

#### Рекомендуемое решение (минимальное)

**Удалить** старые Agassiz-файлы (JE, GUI override, loc).

**Добавить** один патч-триггер (пример логики):

```txt
# Расширить поиск/выбор шахт: bg_mining OR bg_silver_mining OR building_silver_mine
agassiz_can_find_new_vein_trigger = {
    any_scope_building = {
        level > 0
        OR = {
            is_building_group = bg_mining
            is_building_group = bg_silver_mining
        }
        NOT = { has_modifier = agassiz_building_production_mult_modifier }
    }
}

agassiz_mine_valid_for_improvement_trigger = {
    level > 0
    OR = {
        is_building_group = bg_mining
        is_building_group = bg_silver_mining
    }
    NOT = { has_modifier = agassiz_building_production_mult_modifier }
}
```

Отдельный `je_agassiz_find_silver_project` **больше не нужен** — unified JE покрывает silver через выбор здания.

**Проверить при тесте:** AI geology (`mr_ai_geology_scripted_effects.txt`) использует те же триггеры — патч должен покрыть и AI.

### Критичные для компача

| Категория | Ключи | Комментарий |
|---|---|---|
| `common/buildings` | `building_railway` | оба модa INJECT/REPLACE — **не трогать в ef+morg компаче**, load order решает |
| `common/buy_packages` | `wealth_10`…`wealth_99` (90 шт.) | MR добавляет `popneed_entertainment`, E&F — `popneed_currency`; **нужен merge-комpatch или megapack**, ef+morg компatch **не покрывает** |

| `common/history/global`, `states`, `buildings` | `GLOBAL`, `STATES`, `BUILDINGS` | add-on history — обычно OK |
| `common/modifier_type_definitions` | `goods_output_grain_mult`, `goods_output_wood_mult` | дубли определений — низкий риск если load order E&F после MR |

Набор goods Morgenrote не изменился. Новые MR-здания не пересекаются по ключам с E&F.
