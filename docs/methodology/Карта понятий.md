# Карта понятий

## Суть

Вход в граф [[Понятие|понятий]]: одна заметка, с которой видно всё, что в проекте есть, сгруппированным по смыслу.
Человек начинает с неё, агент — тоже, и идёт по ссылкам только туда, куда нужно.

## Правила

- Файл — `понятия/_Карта <проекта>.md`, `type: map`. Подчёркивание — чтобы карта стояла в папке первой.
- Группы по смыслу (устройство, данные, процессы, интерфейс, инфраструктура); строка группы — ссылки через `·` с
  короткой пометкой.
- Каждое понятие есть на карте — [[Проверка]] это смотрит.
- Карта, которой должно хватать для работы без заметок, — у каждого понятия строка с самим правилом, а не только
  ссылка (так устроена карта этого метода — `README.md` его папки): одно чтение даёт всё сжато, заметки —
  подробности.
