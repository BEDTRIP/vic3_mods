### E&F + Morgenroete ComPatch (Vic3 1.13)
### Extend E&F "private ownership -> stocks" switching to Morgenroete buildings.
###
### E&F 4.07.2026 still lists only vanilla / E&F buildings in
### private_ownership_production_stocks, so Morgenroete buildings that carry an
### E&F stock PM group need their own switch.
###
### NOTE (changed in the 1.13 update): this effect is no longer wired in by
### overriding financial_center_ef_on_yearly_pulse_country. That override had
### two problems: it had to be kept byte-in-sync with E&F, and E&F only calls
### that effect for countries that own a financial centre, so Morgenroete
### buildings never switched anywhere else. It is now called from our own
### on_action (common/on_actions/zz_ef_mr_on_actions.txt), which is additive
### and overrides nothing.

			limit = {
				has_building = building_airport
