# ComPatch: The Great Revision + Kuromi AI + Tech & Res
# Load order: CMF -> TGR -> KAI -> T&R -> this patch.
#
# Base = T&R's reworked PMs (new goods, new inputs), because T&R loads last.
# Carried over from TGR: exactly one line per PM,
#   state_modifiers = { unscaled = { state_market_access_price_impact = 0.05 } }
# TGR adds it to every port and railway PM (it does not exist in vanilla) and its
# market-access economy is balanced around it; T&R's rewrite has no opinion on the
# key at all, it simply does not carry it.
#
# 2026-08-23 changes:
#  * Ports resynced with T&R 1.6. The previous patch was still on T&R 1.5 numbers
#    (basic: clippers 5 / laborers 650 / infra 4; industrial: laborers 450;
#    modern: merchant_marine 30 / laborers 350) and, worse, it re-added
#    country_convoys_capacity_add to all three ports. Neither TGR nor T&R has that
#    key any more -- both dropped it independently -- so the patch was inventing
#    convoy capacity that no author wants. Removed.
#  * Dropped five entries that had become exact copies of T&R and therefore did
#    nothing: pm_assembly_lines_building_arms_industry,
#    pm_assembly_lines_building_automotive_industry,
#    pm_assembly_lines_building_motor_industry, pm_automatic_power_looms,
#    pm_electric_fencing. TGR and T&R differ on them, but only in balance numbers,
#    and T&R already wins by load order -- pinning T&R's own values changed nothing.
#  * Still not patched, on purpose: pm_compression_ignition_tractors and
#    pm_rail_transport_mine. Both mods set different numbers there and neither adds
#    state_market_access_price_impact, so there is nothing structural to preserve.
