# Morgenroete <-> Tech & Res: Curtiss script values.

# matches T&R's aircraft industry on its own - curtiss_aeroplane_production_score
# used to be REPLACEd here and was dropped on 2026-08-21 for exactly that
# reason. Check the rest again after each Morgenroete update; the more of them
# go generic, the less of this file is needed.
