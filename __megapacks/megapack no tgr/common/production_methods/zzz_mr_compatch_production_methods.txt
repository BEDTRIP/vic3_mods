# Morgenroete <-> Tech & Res: airport production methods.
#
# THE ONE CONFLICT THIS FILE EXISTS FOR
# Morgenroete adds the good `air_travel` and builds a lot on top of it:
# popneed_entertainment / popneed_leisure / popneed_free_movement,
# prestige_good_generic_flights, the Curtiss airline journal entries.
# All of it is produced by the airport and nothing else produces it.
# Tech & Res cannot ship that standalone - without Morgenroete the good does
# not exist - so its ztr_modified_mr_production_methods.txt re-points every
# airport route PM at goods_output_transportation_add instead. T&R loads after
# Morgenroete, so with both mods on the airport produces zero air_travel and
# every Morgenroete mechanic above quietly dies. No log error, just missing
# content - which is why it went unnoticed for a long time.
#
# WHY SUBSTITUTE AND NOT ADD
# The Tech & Res author left the instruction in their own file, next to each
# affected PM:
#     # Morgenrote compatch basta sostituire l'output con
#     # goods_output_air_travel_add = 12
# i.e. REPLACE the output, do not stack it. The numbers below are theirs
# (12 / 18 / 24 / 30), not invented here. Morgenroete's own airport PMs also
# output air_travel only and no transportation, so both authors agree the
# airport is an air-travel node once Morgenroete is present.
#
# BALANCE CONSEQUENCE - CHECK THIS IN GAME
# In Tech & Res alone the airport is the single biggest transportation source
# in the game (120 / 100 / 75 / 50 per level, above high-speed rail at 80).
# Substituting removes that. If late-game transportation goes short, the fix is
# to put a partial goods_output_transportation_add back here - do NOT cut
# air_travel, everything Morgenroete-side depends on it.
# The pre-2026-08-21 version of this file kept a token 5/10/15/20; those
# numbers came from nowhere in either mod and were dropped for that reason.
#
# Bodies below are Tech & Res 13.05.2026 verbatim except for the output line.
# Re-check them whenever T&R updates: employment and inputs changed silently
# between 04.05 and 13.05 and the old compatch kept reverting them.
#
# NOT here on purpose:
#   pm_air_mail, pm_air_freight, pm_luxury_requisitions - no air_travel in any
#     of them, the old compatch only froze stale T&R numbers.
#   pm_travel_agencies - T&R does not touch it at all, Morgenroete's own
#     version stands. The old compatch moved its unlock from curtiss_tourism_tech
#     (era 2) to international_travel (T&R era 6); that is a balance opinion, not
#     a conflict. If tourism PMs feel too early in T&R's stretched tree, this is
#     where to put that override back.
