# Morgenroete <-> Tech & Res: pop needs.
#
# Morgenroete puts `air_travel` into three pop needs: it defines
# popneed_entertainment outright (air_travel inside) and TRY_INJECTs air_travel
# into popneed_leisure and popneed_free_movement.
# Tech & Res loads later and does REPLACE_OR_CREATE:popneed_entertainment plus
# REPLACE:popneed_leisure, wiping both. popneed_free_movement it only INJECTs,
# so that one survives on its own and is deliberately absent from this file.
#
# INJECT, NOT REPLACE - this is the important part.
# The previous version of this file REPLACEd both needs with a full copy of
# T&R's list plus air_travel. That copy was made from T&R 04.05 and by 13.05 had
# silently reverted a whole balance pass: T&R had dropped `radios` from
# entertainment, dropped `elgar_music` from leisure and retuned about a dozen
# supply shares. A REPLACE here has to be rebuilt by hand every single T&R
# update, and nothing warns you when it goes stale. INJECT only adds the one
# entry that is actually lost, and survives any future T&R retune untouched.
#
# Values are Morgenroete's own, not invented here.
#
# Known side effect: T&R's leisure entry for `civil_planes` stays in place
# alongside air_travel, where the old REPLACE removed it ("pops should buy
# tickets, not aeroplanes"). Two overlapping entries only widen what pops may
# buy; if civil_planes demand visibly distorts, that is the thing to revisit -
# and it would mean going back to a full REPLACE with all its upkeep.
INJECT:popneed_entertainment = {
	entry = {
		goods = air_travel

		weight = 0.25
		max_supply_share = 0.1
		min_supply_share = 0.0
	}
}

INJECT:popneed_leisure = {
	entry = {
		goods = air_travel

		weight = 1.0
		max_supply_share = 0.25
		min_supply_share = 0.0
	}
}
