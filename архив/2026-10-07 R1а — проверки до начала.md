Сделано из облачной сессии через мост `vic3-pc`. Решения пользователя по итогам — Д.1–Д.6, план, раздел «Ночь, этап R1а»;
схема — 3.1, 4.2.

**Инструменты:** `tools/ld_save_roles.py` (роли и торговые центры по сейву; `--keys` / `--market` — разведка структуры
сейва: записи менеджеров с нулевым отступом, поля — один таб; `market_manager.database` — только `owner`),
`tools/ld_r1a_checks.py` (eflog: EFW против EFR, зонд EFD, `d_tc` против `trade`), слово `minimized` в `-Commands`
скрипта прогона (`run_vic3_sandbox.ps1 -Minimized`). Зонд казны `EFD` (`ld_diag_r1a_on_actions.txt`: 42 дня с первого
месячного пульса каждая страна пишет строку, если `zz_ef_budget_position` изменилась за день) жил только в ветке проверки
форка и убран.

**Прогоны:** r1007_161644 — новая игра за Швейцарию, окно обычное, 1836.1–1840.8; r1007_164303 — то же, окно свёрнуто,
1836.1–1839.12, в конце вылет. Сейв — `autosave.v3` 1836.7.1 (прогон r1007_142609). Для Р8 / Р2 также r1007_131906.

## Итоги

Из ревью R0.8 (номера Р — там же). Прогоны r1007_161644 (окно обычное, 1836.1–1840.8) и r1007_164303 (окно свёрнуто,
1836.1–1839.12, вылет в конце — ниже); сейв 1836.7.1; `tools/ld_r1a_checks.py` (eflog), `tools/ld_save_roles.py` (сейв),
режим `minimized` скрипта прогона. Временный зонд казны `EFD` — только в ветке проверки форка, убран.
- [x] **Мост при свёрнутом окне** (Р8): приёмники срабатывают и при свёрнутом окне — у логируемых стран (7) пропусков
  нет ни в обычном прогоне, ни в свёрнутом; при свёрнутом приёмники идут пачками (862 дня из 1438 против 1650 из 1695),
  недели не теряются. Правило «модель живёт без моста» остаётся (мультиплеер, Р9), но срочности нет.
- [x] **Бюджетный тик — один день у всех** (Р10): казна меняется в один день недели у 280 из 289 стран (у 9–20 — на день
  позже, это скриптовые изменения поверх); прочие дни — по ~110–150 изменений от скриптов (месячные шаги E&F). →
  планировщик на **одной глобальной цепочке** от дня тика, зонды стран не нужны.
- [x] **Роль В** (Р17), сейв 1836.7.1: 442 страны — `decentralized` 158, `unrecognized` 185, `recognized` 80, `colonial`
  16, `company` 3. У децентрализованных: свой рынок у каждой, **торговых центров 0** (торговли нет), казна в сумме 111 тыс.,
  пула нет, из зданий кроме натуральных — 250 поместий и 2 золотых прииска. → мировой счёт В для клиринга **не нужен**;
  золото приисков В — в R2 (Р21). **Сейчас модель денег идёт у всех 442 стран, включая В** — исключение В снимает ~36 %
  поштучной работы. Оценка ролей поправлена: А ~55, **Б ~230** (не ~100), В 158; 40-я страна по ВВП — 1,23 млн, 50-я — 0,78 млн.
- [x] **Торговля — какая мера** (Р2): изменение кассы торговых центров (`d_tc`) в десятки раз меньше торговли рынка
  (`trade`, базовые цены с kr / kp) и с ней почти не связано (корреляция по странам −0,4…0,5; Британия за 4,5 года:
  Σd_tc 0,13 млн против Σtrade 3,8 млн). → мера торговли — **торговля рынка**; касса торговых центров — часть кассы
  бизнеса (M1), а не платёж за границу.
- [x] **Источник сбережений населения** (Р1): прямого нет. Скрипт видит у попа только уровень `wealth` (не деньги), у
  страны — `investment_pool_gross_income` / `_net_income`, `income`; GUI — `Pop.GetIncome` / `GetExpenses` (поштучно по
  попам — дорого), `PopsOverviewPanel.GetIncomeRemainder{Poor,Middle,Rich}` (только у открытой панели населения игрока).
  → своя оценка; кандидат — взносы попов в пул (`investment_pool_gross_income`), проверить, входит ли туда наш
  `add_investment_pool`.
- [x] **On_action смены страны игроком** (Р15): нет (`on_actions.log` 1.13; есть только `on_game_started_after_lobby`). →
  ловить мостом (`GetPlayer`) и `is_player` на месячном шаге.
- [x] **Хук смены методов** (Р30): `ef_on_production_method_changed` на **каждую** смену метода любого здания перебирает
  все штаты владельца × 48 типов зданий (98 проверок `private_ownership_fraction` на штат,
  `private_ownership_production_stocks`, `01_financial_scripted_effects.txt:25478`); тот же перебор раз в год
  (`financial_center_ef_on_yearly_pulse_country`). PM акций (`pm_private_ownership_majority_*_stock`, выход акций 12,5)
  условий движка не имеют — переключает только хук. Сузить можно: область хука — здание (`owner = …`), у здания есть
  `has_active_production_method` и `private_ownership_fraction` → проверка одного здания вместо страны.
**Решения пользователя 7.10 (по итогам проверок):**
