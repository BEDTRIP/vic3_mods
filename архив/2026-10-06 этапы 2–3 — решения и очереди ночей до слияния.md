Решения для ночи:
- **Д2.7б — облигации ЦБ = заём казны у населения, бессрочные «консоли»** (пользователь 5.10). Выручка от товара E&F

  держателями; проценты по ставке правительства — из казны в накопления населения; погашения нет, при излишке казны —
  выкуп части долга. Связать с В5.3 (проценты по держателям) и показом в карточках.
- **Д2.8 — банки: посев по 500 на уровень, штат 1000 служащих** (без капиталистов — их найм не идёт).
- **Д2.9 — частные банки E&F остаются** (пользователь: «удалять средства банков не собираюсь; здания — затычка, чтобы
  показать товар E&F как услуги расчётов; банки всё ещё выдают кредиты и служат инвестпулом»). **Прибыль здания «Банк»
  компании-банка E&F — в средства этого банка** (`*_company_<банк>_fixe` / как E&F хранит средства), убыток — из них;
  здания других владельцев — как есть. Отменяет прежнее «средства банков E&F → в пул» (Д2.6 в части средств).
- **Д2.10 — биржа: котируется всё, что имеет метод «публичная компания»** (пользователь: «этот метод должен стать очень

  финцентры E&F с таким методом. **Капитализация = стоимость котируемых: их годовые дивиденды / (ставка правительства +
  премия за риск акций ~4 п.п.)** — цель «сама выходит ~0.3 ВВП Британии в 1840-х и ~1.0 к 1913, без ведения индекса за
  руку» (EF.35). Товары-акции E&F — оборот биржи, не капитализация.
- **Д2.11 — кто публичный (скрипт, раз в месяц):** в стране есть биржа (финцентр E&F) + закон допускает частные
  акционерные общества (не традиционализм) + компания достаточно крупная (доля компаний страны по уровням растёт с
  грамотностью богатых — EF.25 / EF.22); нет биржи — метод снимается.
- **Д2.12 — EF.47 без биржи:** методы акций зданий E&F переключает сам; наш скрипт переключает «публичную компанию»
  (Д2.11) — без биржи нет котируемых, капитализация 0 (сгорает через годовое среднее).
- **Итоговый прогон ночи** — новая игра за Швейцарию до ~1845 (40 мин).

## Этап 3 — решения (пользователь, 5.10 вечер)

**6.10: этап 3 слит в этап 2 (шаг Ф7 и Ф1); Д3.1–Д3.3 и Д3.5 пересмотрены ответом М — металл только с рынка, без 50/50 чеканки;
очередь «Ночь, этап 3» ниже не запускать — новые очереди пишутся по шагам Ф1–Ф8.**

Приняты днём 5.10 вместе с ночью этапа 2; ночь этапа 3 идёт **в ту же ночь, после этапа 2** (раздел «Ночь, этап 3»).

- **Д3.1 — металл — замкнутый контур счетов, как деньги** (пользователь: «золото и серебро — такой же набор счетов без
  утечек; пополняется шахтами/приисками; за всю игру лишнего золота/серебра не должно возникнуть из ниоткуда и не
  пропасть»). Золото и серебро — отдельно. Счета страны: **ЦБ**, **население**, **частные банки E&F** (Д3.5),
  **«ушло в товары»**. Приход страны в неделю = добыча (`zz_ef_gold_mined_week` / `_silver_`) **минус металл, купленный
  на вход прочими зданиями** (если такие есть: ювелирки в игре нет — проверить по сейву `scan_goods_io`); **здание ЦБ металл
  не потребляет** — его покупка (Д2.7а) — перевод в резервы, под него выпускаются деньги. Между странами металл ходит только
  парами (клиринг, Юм, сделки ЦБ) — мировая строка: Σ счетов = Σ добычи − Σ «ушло в товары» + стартовые запасы.
- **Д3.2 — чеканка 50/50 из прихода:** половина прихода — в резервы ЦБ (ЦБ платит владельцам деньгами, как сейчас
  `zz_ef_mint_share`, но из прихода, а не сверху), половина — в металл населения. Покупка металла зданием ЦБ (Д2.7а) —
  из металла населения (ЦБ купил его на рынке), не из ниоткуда. ЦБ выкупает металл у населения по паритету при высоком
  доверии (брассаж 1%) — из В8.1. Страна без ЦБ — весь приход населению.
- **Д3.3 — старт:** металл населения в 1836 = доля ВВП, больше там, где нет ЦБ (тезаврация: без ЦБ ~20% ВВП, с ЦБ ~5%;
  числа — «принято ночью, проверить»); разовое начальное условие, отдельная строка лога; дальше — только шахты.
- **Д3.4 — корзина накоплений (В8.1) — только по доходности:** сверх нормы наличных (как сейчас) накопления делятся между
  вкладами (ставка по вкладам), бумагами (доходность биржи по Д2.10) и металлом (доходность 0 + **премия за недоверие** =
  инфляция за год + покрытие ЦБ ниже 40% (резко — при приостановленном размене) + индекс настроений E&F (EF.31, Д4.6) +
  нет ЦБ и зданий «Банк» — металл почти целиком). Правило дележа и скорость сдвига — «принято ночью, проверить» (не
  «всё в одно»: доли от разницы доходностей, сдвиг — доля разрыва в неделю, как наличные ↔ вклады).
- **Д3.5 — металл частных банков E&F — счёт контура** (закрывает В2.13): банки покупают металл у населения или ЦБ и не
  уходят в минус; металл, который E&F создаёт банкам из ниоткуда, — вырезать.
- **Д3.6 — бумаги населения = деньги в пул с пометкой «доля населения»** → частная стройка этой доли — на население
  (СТР.5, цель — 20% частных прибавок); доход — доля дивидендов публичных компаний по доле населения в капитализации.
- **Д3.7 — валютный счёт населения (П.12) — этап 4** (с кризисами, В8.2).
- **Д3.8 — кредиты (В5.2) — сначала прогон:** ночью только замер после В8.1 (часть разбухания может уйти сама); потолки —
  решение по замеру.
