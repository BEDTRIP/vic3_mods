[h1]Hail, Columbia! + Gates of the Bosphorus + Mandate of Heaven  +  Victorian Century ComPatch[/h1]

Compatibility patch for using the [b]Hail, Columbia! / Gates of the Bosphorus / Mandate of Heaven[/b] block together with [b]Victorian Century[/b].

Built 26.08.2026, against [b]Hail, Columbia! 8.6-Roosevelt[/b], [b]Gates of the Bosphorus 4.0.8[/b], [b]Mandate of Heaven 1.4.6.1[/b] and [b]Victorian Century[/b] (unpacked 2026-08-25, the mod declares no version).

Generated by [i]tools/regen_hc_vc.py[/i] from source-mod files plus a hand-filled decision spreadsheet ([i]hc_vc_character_traits.xlsx[/i]) for the character-trait picks -- never hand-edit the output files under [i]common/[/i] directly, re-run the generator instead. Full conflict analysis for the whole pair: [i]conflicts_hcgobmoh_vs_vc_report.md[/i].

[b]This is not the whole HC+GoB+MoH x VC pair.[/b] Five of its items -- [i]ig_landowners[/i], [i]ig_rural_folk[/i], [i]common/history/countries/chi - china.txt[/i], [i]tur - ottoman empire.txt[/i] and [i]usa - usa.txt[/i] -- REPLACE paths that [i]hc+tgr done[/i] already owns a winning copy of, so their VC layer was built into that pair's generator ([i]tools/regen_addon1.py[/i]) instead of duplicating the file here under a second REPLACE:. See [i]hc+tgr done/README.md[/i] for those five.

[*]Every decision and its reasoning is recorded per-row in the spreadsheet; the generator asserts the spreadsheet's 15 keys match exactly before writing anything.

[h2]Checked and deliberately left alone[/h2]
[list]
[*][b]ig_armed_forces, ig_intelligentsia, ig_petty_bourgeoisie, je_autocracy, state_trait_columbia_river, NAI.[/b] MoH/HC only [i]INJECT:[/i] into sub-blocks or fields VC's much larger [i]REPLACE_OR_CREATE:[/i] body doesn't occupy. Additive, confirmed line by line.
[*][b]CHI_minguo (coat_of_arms).[/b] MoH's and VC's bodies are byte-identical after normalization -- same 1928 Republic-of-China flag, same source. Whichever wins the path, the picture is the same.
[*][b]manifest_destiny.txt.[/b] Both HC and VC independently suppress the vanilla decision (HC replaces it with its own 1100-line journal chain; VC ships an 11-byte stub). Nothing to restore -- same call already made for HC x TGR.
[*][b]map_data/state_regions: STATE_GANSU, STATE_GUANGDONG, STATE_HINGGAN.[/b] MoH ships the whole vanilla East-Asia region as a bare body; VC ships its own 16-file world map. With this composition's load order (VC, then this addon), MoH's bare body wins automatically and these three states come out vanilla/MoH-shaped, not VC's. No compatch needed -- flagged here only so a build without MoH, or without VC, doesn't assume this outcome still holds.
[*][b]chi_daoguang_template.[/b] Vanilla defines it; VC REPLACE_OR_CREATE:s it early (adds [i]basic_political_operator[/i] to vanilla's [i]traits[/i], nothing else touched); MoH INJECT:s [i]on_created[/i] late (an effect block VC's body never names). Load order alone makes MoH's injection land on top of VC's traits rewrite -- no path or key actually collides.
[*][b]common/dna_data: Li Hongzhang, Zhang Zhidong, Zuo Zongtang.[/b] Named in the original pair-matrix scan; re-checked while building [i]ecchi_usa_polk.txt[/i] above and found to be [b]not[/b] the shared-source case Polk's DNA is -- MoH's three files (115-117 lines) and VC's (649-661 lines) are unrelated, independently-authored portraits under the same declaration key, MoH's plain and VC's far more detailed. Left as-is (MoH wins the path, same as today): both mods' own character_templates reference these DNA keys for their own version of these reform-era officials, and MoH's own China political system -- already established as the one this composition runs on (see [i]chi - china.txt[/i] in [i]hc+tgr done[/i]) -- is what these portraits belong to. Splicing in VC's richer DNA would put VC's character design under MoH's own characters. Not the one-line merge it looked like; a real, if low-stakes, editorial call, not a technical oversight.
[/list]
