[h1]Hail, Columbia! + Gates of the Bosphorus + Mandate of Heaven  +  The Great Revision + Victorian Century ComPatch[/h1]

Compatibility patch that puts [b]Victorian Century[/b] on top of [url=]Addon 1: HC + GoB + MoH x MegaComPatch[/url] (the merged [b]Hail, Columbia! / Gates of the Bosphorus / Mandate of Heaven[/b] block, against [b]The Great Revision[/b]'s numbers Addon 1 already carries).

Built 26.08.2026, against [b]TGR 2.0 (1.13.10)[/b], [b]Hail, Columbia! 8.6-Roosevelt[/b], [b]Gates of the Bosphorus 4.0.8[/b], [b]Mandate of Heaven 1.4.6.1[/b] and [b]Victorian Century[/b] (unpacked 2026-08-25, the mod declares no version).

Generated by [i]tools/regen_hc_vc.py[/i] from source-mod files, [b]Addon 1[/b]'s own generator ([i]tools/regen_addon1.py[/i] -- imported, not copied) and a hand-filled decision spreadsheet ([i]hc_vc_character_traits.xlsx[/i]) for the character-trait picks -- never hand-edit the output files under [i]common/[/i] directly, re-run the generator instead. Full conflict analysis for the whole pair: [i]conflicts_hcgobmoh_vs_vc_report.md[/i].

[b]Why this is a separate compatch and not part of Addon 1.[/b] Until 26.08.2026 all of Victorian Century's content for this block was folded straight into Addon 1's build. In practice, running Victorian Century and the whole HC+GoB+MoH block together turned out too heavy -- noticeable lag even on a near-top-end PC -- so there was no point forcing everyone who wants the HC block to also carry VC's weight. Victorian Century's content was pulled out of Addon 1 entirely and put here instead, so it can be added on top for players who want it and skipped cleanly by everyone else -- no file surgery, no [i].off[/i] twins, just install this compatch or don't.

[*][b]The USA gets twelve of Victorian Century's fourteen Bill-of-Rights amendments[/b]
[list]
[*]This one ships Hail, Columbia!'s own file directly rather than REPLACing Addon 1's output -- The Great Revision never touches [i]usa - usa.txt[/i], so it has no base in Addon 1 to layer onto. HC and VC pick laws in fifteen groups; ten agree outright and five compete (trade policy, economic system, free speech, taxation, church and state) -- HC's own picks win all five, same principle as everywhere else in this addon: three of the five are laws HC wrote for itself. What still carries regardless of who wins those five: an amendment attaches to whichever law is active in its group, not to one specific law, so twelve of VC's fourteen [i]active_law:lawgroup_X ?= { add_amendment = {...} }[/i] blocks are safe (two were already byte-identical to ones HC ships itself).
[*]Not carried: VC's own tariff setting and its entire parallel American journal/variable/modifier chain (a second "real manifest destiny" system, on top of HC's own 1100-line one) -- the same [i]manifest_destiny.txt[/i]-precedent call as below, just for the USA instead of Oregon.
[/list]

[h2]Checked and deliberately left alone[/h2]

Left as-is (MoH wins the path, same as today): both mods' own character_templates reference these DNA keys for their own version of these reform-era officials, and MoH's own China political system -- already established as the one this composition runs on -- is what these portraits belong to. Splicing in VC's richer DNA would put VC's character design under MoH's own characters. Not the one-line merge it looked like; a real, if low-stakes, editorial call, not a technical oversight.
