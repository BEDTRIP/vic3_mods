# HC + GoB + MoH × Morgenröte — разбор пары

Дата разбора: 2026-08-24. Игра 1.13 (exe 1.13.11).
Версии: Morgenröte 2.8.3e, Hail, Columbia! 8.6-Roosevelt, Gates of the Bosphorus 4.0.8, Mandate of Heaven 1.4.6.1.
Порядок: CMF → … → Morgenröte → … → HC → GoB → MoH → **компач**.

Машинный прогон `pair_matrix.py --pair "HC+GoB+MoH,Morgenrote"`: **26 общих ключей, 21 общий путь файла, 0 общих id событий.**
Из них содержательных — четыре. Остальное разобрано ниже как «не конфликт».

## Требуют работы — сделано

### 1. `gaudi_capital_expansion_level_4_modifier` — заглушка гасит модификатор

| | тело | что в нём |
| --- | --- | --- |
| ваниль | — | ключа нет, это модификатор Morgenröte |
| Morgenröte | 10 строк, `mr_arts_gaudi_modifiers.txt` | икона + 8 стейтовых модификаторов |
| Gates of the Bosphorus | 3 строки, `zz_gbbf_placeholder_modifiers.txt` | только `icon` |

GoB держит заглушку, чтобы его журнал Византии (`1-20_grefm_byzantium.txt`, `has_modifier = gaudi_capital_expansion_level_4_modifier` под гейтом `morgenrote_is_active = yes`) резолвился, когда Morgenröte не установлен. Само по себе разумно. Но GoB грузится позже Morgenröte, а голое тело заменяет запись целиком — и при обоих модах уровень 4 у Гауди теряет все восемь модификаторов и остаётся иконкой. В логе ничего: ключ существует.

**Решение:** файл компача переиздаёт тело Morgenröte последним. Гейт GoB продолжает работать (ключ есть при любом наборе).

### 2. `revise_olympic_games_decision` — две Олимпиады сразу

| | что делает |
| --- | --- |
| ваниль | одноразовое решение «возродить Олимпийские игры» |
| Morgenröte | `TRY_REPLACE:` с `is_shown = always no` — гасит его, потому что везёт свою систему (Vikelas: журнал, scripted GUI, трейты, PM, алерты) |
| Gates of the Bosphorus | `REPLACE:` на 44 строки — переписывает в греческое решение (Аттика + `organized_sports`, два модификатора) |

GoB позже, поэтому сейчас у игрока и полная система Morgenröte, и второе, независимое от неё решение. Не баг ни у кого, в логе ничего — просто дублирование контента.

**Решение (развилка, закрыта 24.08.2026):** побеждает Morgenröte. Компач переиздаёт подавление. Греция теряет одно флейворное решение.

### 3. Уолтер Крайслер и Марк Твен — два мода, одна запись

| под-блок | Morgenröte | Hail, Columbia! |
| --- | --- | --- |
| `role` | `character_role_tesla_engineer` / `character_role_manzoni_writer` | — |
| `traits` | инженерные / писательские + жанр | предпринимательские / литературные |
| `on_created` | регистрация в системах MR | у Крайслера нет, у Твена — лестница идеологий (на `has_law_or_variant`, новее) |
| usage | — | `executive_usage` (Basic Motors, 1915–1940) / `agitator_usage` (Миссури, 1865–1910) |
| `dna` | свой у Твена | нет у Твена |

Оба тела HC — голые, HC грузится позже, запись заменяется целиком. Персонажи остаются, но перестают быть инженером и писателем Morgenröte: ни роли, ни `on_created`. Молча.

**Решение (развилка, закрыта 24.08.2026):** мердж. База — тело HC (последнее полное и более специфичное: это американские персонажи в американском флейвор-моде), сверху роль MR, две несущие механику трейты и `on_created`. Чисто описательные трейты MR не переносятся — иначе список вырастает до семи.

**Риск, который надо проверить в игре:** `role` рядом с `executive_usage` / `agitator_usage` — конструкция, которой нет ни в ванили, ни у одного из авторов. Смотреть, не появляется ли персонаж дважды.

### 4. `common/achievement_groups.txt` — экран достижений

У файла нет top-level ключей: это список анонимных блоков `group = {}`. `INJECT:` не к чему цеплять, единственный инструмент — перекрытие по пути, и последний мод забирает файл целиком.

| | содержимое |
| --- | --- |
| ваниль | базовые группы |
| Morgenröte | ваниль + 12 своих групп (~60 достижений) |
| Mandate of Heaven | более старая ваниль + свои достижения в существующие группы; **нет** `achievement_exactly_100` |

MoH последний → пропадают все 12 групп Morgenröte и одно ванильное достижение. В логе ничего, достижений просто нет на экране.

**Решение:** файл MoH + возвращённое `achievement_exactly_100` + группы Morgenröte в хвост.

## Не конфликты

| ключ / путь | сколько | почему не конфликт |
| --- | --- | --- |
| 18 × `common/dna_data/mr_*.txt` (GoB) | 18 путей + 18 ключей | GoB везёт свои копии портретных файлов Morgenröte. Расхождение — только гены портрета (в основном `gene_stubble` 0 → 127) и вырезанная строка редактора. Намеренные варианты, а не стухшая копия: один файл вообще побайтово совпадает |
| 2 × `common/dna_data/ecchi_usa_*.txt` (HC) | 2 пути + 2 ключа | то же, HC переделывает портреты Крайслера и Линдберга целиком |
| `pmg_luxury_building_glassworks` | 1 | ваниль (голое) → Morgenröte `TRY_INJECT` → T&R `INJECT` → MoH `INJECT`. Все три — в `production_methods`, инжекты в список складываются |
| `community_framework_is_active` | 1 | штатный фолбэк `always = no` у каждого CMF-совместимого мода; сам CMF перекрывает его из `zz_com_detection_trigger.txt` |
