# vic3_mods — правила для агента (загружается автоматически)

Репо пачки проекта vic3: **компачи, мегапаки, аддоны, переводы**, генераторы `tools/`, мост `vic3-pc` (`tools/pc_bridge`,
`bridge.toml`) и проектный навык `vic3-sandbox`; вход — `README.md`. Общие правила проекта — git всех репо, `v3`,
навыки, прогоны и ночи — **`../CLAUDE.md` узла**; план и этапы — узел (`../docs/план.md`, этап «П. Пачка»).

Что делает чужой мод — документы источников `../vic3_mods_out/docs/<источник>/`; компачи строятся по их графам (решение
узла Д.ДОК.14). Справочник набора — `docs/Порядок запуска и матрица.md`; правила пачки (README компача, статусы пар,
разбор конфликтов) — `Правила — проект.md`.

## git — особое для пачки

- Ветка `main`. Порядок коммитов задачи: компач / хотфикс + генератор → аддоны → мегапаки → документы.
- Остальное — `../CLAUDE.md`, «git».
